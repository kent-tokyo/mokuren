# mokuren v0.2.0-in-progress major-mode chorale baseline (secondary dominants + soprano-range fix)

Generated by `examples/chorale_benchmark.rs` against the same 144 chorales as [`tasks/baseline-v0.1.0.md`](baseline-v0.1.0.md) (re-extracted locally via `tools/music21_chorale_extractor.py`, identical corpus). This file contains only chorale **titles**, **Riemenschneider catalog numbers**, and **mokuren's own computed statistics** — no encoded musical content — same non-vendoring stance as the v0.1.0 baseline (BENCHMARK.md).

**Comparison against `tasks/baseline-v0.1.0.md`**: coverage rose from 50.7% (73/144) to **91.7% (132/144)** — a +41.0pt absolute, +81% relative improvement, from implementing applied dominants (`RomanNumeral::applied_to`, ROADMAP.md phase 2) and fixing the soprano-range ceiling (ROADMAP.md phase 5, G5→A5). 0 hard-rule violations, same as v0.1.0.

**Regression check**: per-chorale diff against the v0.1.0 baseline found 4 chorales (Riemenschneider 101, 135, 230, 303) that succeeded at width 32 before and fail at width 32 now — the vocabulary roughly doubling means more candidates compete for the same fixed beam width at each position (the horizon effect, README limitation #4, got measurably worse — see `tasks/lessons.md`). All 4 were confirmed to still succeed at a wider beam (2 at width 64, 2 at width 512 — verified directly, not assumed), so none is a new structural failure; all are the same known, already-documented beam-width/vocabulary-size trade-off, not a correctness regression. The default beam width (32) was deliberately *not* raised to compensate — the two chorales needing width 512 would make 32 a very expensive default for a rare case (see `tasks/lessons.md`'s note on the v0.1 spine-melody investigation, where widths in the hundreds were also needed for one specific case). `examples/chorale_benchmark.rs`'s failure-classification retry ladder (`RETRY_WIDTHS`) was widened from `[64, 128, 256]` to `[64, 128, 256, 512]` so these get classified as `SearchExhausted` correctly rather than falling through to `Other`.

**Remaining failures** (12/144): 6 search-exhausted (recoverable with a wider beam — the 4 above, plus Riemenschneider 183 and one more), 6 still classified `Other` (undiagnosed even at width 512) — not yet individually root-caused; likely a mix of chromatic tones applied dominants don't cover (modal mixture, non-chord tones outside the V/x, V7/x set) and possibly other new interactions. Tracked in `tasks/todo.md` as follow-up, not blocking.

Reproduce: `python3 tools/music21_chorale_extractor.py -o <dir>` then `cargo run --release --example chorale_benchmark -- <dir> --report tasks/baseline-v0.2.0-secondary-dominants.md`. Extracted `.chorale` files are never committed (deleted after each run, per "reference, don't vendor").
