# mokuren v0.1.0 major-mode chorale baseline

Generated by `examples/chorale_benchmark.rs` against 144 chorales extracted locally via `tools/music21_chorale_extractor.py` (BENCHMARK.md). This file contains only chorale **titles**, **Riemenschneider catalog numbers**, and **mokuren's own computed statistics** (coverage, cost, runtime, etc.) — no encoded musical content (no note sequences, no pitches beyond the aggregate numbers above). That's a different thing from vendoring the corpus (which this repository still doesn't do, per BENCHMARK.md's "reference, don't vendor" decision): titles and catalog numbers are bibliographic facts, not the chorales' musical expression.

This is the reference baseline mentioned in README's "Current limitations" and ROADMAP.md's phase 1. Re-run to reproduce: extract the same corpus (same music21 version — see below) and run `cargo run --release --example chorale_benchmark -- <dir> --report tasks/baseline-v0.1.0.md` against it.
